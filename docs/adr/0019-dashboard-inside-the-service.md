# 0019. Дашборд — страница самого сервиса, тревоги — задачи GitHub

> Тревоги теперь сразу приходят владельцу в Telegram, а задача «алерт»
> осталась сторожем на случай, если лёг весь сервер
> ([ADR-0022](0022-telegram-bot-inside-the-service.md)).

Владельцу нужен дашборд: активность людей, нагрузка сервера, ошибки и
тревоги ([016-dashboard](../../specs/016-dashboard.md)). Обычный ответ —
Grafana с Prometheus и экспортёрами. Здесь его нет: дашборд — страница
`/dashboard` того же бинарника, цифры — из той же базы.

## Почему не Grafana и Prometheus

Прод — одно ядро и 2 ГБ памяти, на них же Postgres
([ADR-0004](0004-binary-and-systemd-in-production.md)). Grafana,
Prometheus, node_exporter и экспортёр Postgres вместе держат 300–400 МБ
и добавляют четыре программы, которые надо ставить, обновлять и
закрывать от интернета. Ради двадцати человек это больше, чем сам сервис.

Главное на дашборде — посты, лайки, комментарии, люди — и так лежит в
базе: это `count(*)` по дням. Нагрузка машины — три файла в `/proc` и
`statfs`, раз в минуту в таблицу. Ошибки сервис видит сам, когда отвечает
`500`. Отдельная система метрик здесь только перекладывала бы эти числа
из одного места в другое.

## Почему не в контракте

`/dashboard` и `/dashboard/data` не описаны в `specs/openapi.yaml`:
контракт — это то, что зовёт приложение
([ADR-0001](0001-spec-first-openapi.md)), а дашборд зовёт только его
собственная страница. Форма данных записана в спецификации фичи, тесты
проверяют её так же, как остальное
([ADR-0002](0002-tests-as-the-only-gate.md)).

## Доступ

HTTP Basic с одним паролем из `/etc/moya-dacha.env`. Ролей
«администратор» в модели пользователя нет
([ADR-0017](0017-reports-handled-from-the-console.md)), заводить их ради
одного человека — лишнее. Браузер запоминает пароль, а без пароля
дашборда в сервисе нет вовсе.

## Тревоги

Сервер сам о своей смерти не расскажет, поэтому проверяет его снаружи
прогон GitHub Actions по расписанию, а сообщает — задачей в репозитории
с меткой «алерт». Приложение GitHub на телефоне у владельца уже стоит
([ADR-0013](0013-testing-from-a-phone.md)): новых аккаунтов, ботов и
ключей не нужно. Telegram, почта и SMS отвергнуты тем же решением, что и
сводки в Telegram: всё в одном месте.

## Чем платим

- Раз в два часа — не мгновенно. Упавший сервер владелец может увидеть
  позже тестировщиков. Чаще — дороже: каждый прогон — минута из
  бесплатных минут Actions.
- Нет задержек по ручкам, разбивки запросов, произвольных запросов к
  метрикам. Когда понадобятся, первым кандидатом будет `/metrics` в
  формате Prometheus из того же бинарника, а не сразу Grafana.
- Измерения живут 14 дней, ошибки — 30: истории за год нет.
