# Спецификация: «Кто увидит» — только участники группы

## Статус
В работе

## Зачем (контекст)
«Кто увидит» ([013](013-post-visibility.md)) знает три ответа: все,
друзья, только я. Соседям по СНТ этого мало: «в Ромашке отключат воду»
или «у кого есть лишний мешок навоза» — разговор для своих, а не для
всей «Моей дачи» и не только для взаимных подписок.

Пост в группе ([030](030-group-posts.md)) отвечает на вопрос *где* пост
покажется; эта фича добавляет ответ на вопрос *кто вообще* его увидит:
«Только участники снт Ромашка». Разбор — `plan/groups-v2.md` в файлах
проекта, пункт 5 и «Технический риск».

Задача: [#109](https://github.com/gmu-msk/moya_dacha/issues/109), эпик
[#74](https://github.com/gmu-msk/moya_dacha/issues/74).

## Пользовательский сценарий

**Дано:** Николай — в геогруппах «снт Ромашка» и «д Липки» (две дачи) и
в группе по интересам «Любители рыбалки». Галина — в «снт Ромашка».
Сергей подписан на Николая взаимно, но ни в одной его группе не состоит.

1. Николай открывает «Новый пост». «Кто увидит» — список сверху вниз:
   «Все», «Друзья», «Только я», «Только участники д Липки», «Только
   участники снт Ромашка», «Только участники Любители рыбалки». У каждой
   строки значок, название, пояснение и кружок выбора.
2. Он выбирает «Только участники снт Ромашка». Ниже, в «Выложить в
   группе», сама ставится галочка и отмечается «снт Ромашка»; снять эту
   отметку нельзя.
3. Публикует. В карточке рядом со временем — «участникам группы», под
   автором — «в группе снт Ромашка».
4. Галина видит пост в «Подписках» и в ленте группы, может отметить его
   и прокомментировать. Сергей не видит его нигде, а по ссылке получает
   «пост не найден».
5. Николай выходит из «снт Ромашка». Галина пост по-прежнему видит;
   Николай видит его в своём профиле как свой.

## Функциональные требования

### Видимость
1. Новый вариант видимости поста — «только участники группы X». Он
   задаётся полем `visibility_group_id` в `POST /api/posts`. Нет поля,
   `null` или пустая строка — видимость как раньше, по `visibility`.
2. Выбрать можно только группу, где автор — участник (`member` или
   `owner`, 029) и которая ему видна. Иначе — нет группы, не UUID,
   автор только приглашён, вышел или группа ему не видна —
   `403 not_group_member`, пост не создаётся. Проверка идёт вместе с
   проверкой `group_ids` (030, требование 2): после тэгов, до места.
3. Если `visibility_group_id` есть, поле `visibility` в запросе сервер
   не учитывает (лишь бы оно было из трёх известных значений, иначе
   `400 invalid_request`, как раньше). Приложение шлёт в нём `me`:
   сервер без этой фичи пропустит неизвестное поле мимо и выложит пост
   «только мне», а не всем.
4. Пост с видимостью группы X сам выкладывается в X (030): X попадает в
   его `groups`, даже если её нет в `group_ids`. Повтор схлопывается.
5. Пост с видимостью группы X виден автору и участникам X (`member`,
   хозяин — тоже участник), которым X видна (029, требование 16).
   Больше никому: ни друзьям, ни подписчикам. Приглашённому в X — нет.
6. Проверка одна на сервере, та же, что у остальной видимости (013,
   требование 4): обе вкладки ленты, лента группы, посты пользователя,
   пост по адресу, лайки, комментарии, жалобы, уведомления, число
   постов в профиле. Невидимому — `404 post_not_found`. Блокировки
   (022) действуют как всегда.
7. Видимость считается в момент запроса (013, требование 5): вступил в
   X — пост появился; вышел или убрали — пропал.
8. Автор вышел из X или его убрали — пост по-прежнему видят участники
   X, а автор видит его как свой: везде, где видит свои посты.
9. Группу X удалили (только группу по интересам; геогруппу удалить
   нельзя, 029) — пост остаётся у автора с видимостью «только мне».

### Как это видно в ответе
10. У `Post` поле `visibility` — по-прежнему одно из трёх. У поста с
    видимостью группы оно `friends`: старая сборка покажет «друзьям» и
    не упадёт на незнакомом значении.
11. Новое поле `visibility_group` (`id`, `name`) — группа видимости;
    у остальных постов его нет или `null`. Приложение, увидев его,
    показывает видимость группы, а не `visibility`.

### Смена видимости
12. `PUT /api/posts/{postId}/visibility` с `all`, `friends` или `me`
    снимает видимость группы: дальше пост виден по новому значению.
    Группа остаётся в `groups` поста (030, требование 5).
13. Поставить видимость группы опубликованному посту нельзя: в меню
    поста групп в списке нет, кроме текущей.

### Приложение
14. «Кто увидит» в новом посте — вертикальный список: «Все» («Подписчики»
    у закрытого профиля), «Друзья», «Только я», затем «Только участники
    <группа>» — по строке на каждую группу, где человек участник или
    создатель (029, `scope=mine`). Сначала геогруппы, потом группы по
    интересам; внутри — по названию без учёта регистра.
15. Строка — значок, название, пояснение и кружок выбора; выбранная —
    на подложке (013, требование 8). Пояснение у группы — «Пост увидят
    только участники группы»; значок — группа людей.
16. Выбрана группа X — в «Выложить в группе» (030, требование 16) сама
    ставится галочка и отмечается X; эти две отметки не снимаются, пока
    выбрана X. Другие группы отметить можно. Выбрали другой вариант —
    отметка X снимается, если человек не ставил её сам.
17. Отметка на карточке и на экране поста рядом со временем — значок
    группы людей и «участникам группы».
18. Меню своего поста «Кто увидит» — тот же список из трёх строк; у
    поста с видимостью группы под ними — строка этой группы, выбранная.
    Сообщение после смены — как в 013; после выбора той же строки
    ничего не происходит.

## Вне рамок (Out of scope)
- Поставить видимость группы уже опубликованному посту (требование 13).
- Видимость сразу нескольких групп («участникам Ромашки и Липок»).
- Уведомления и пуши участникам о новом посте группы.
- Сборка из PR на сервере с main: пост с выбранной группой выйдет
  «только мне» и без группы (требование 3) — это ожидаемо.

## API / контракт данных

Контракт целиком — в [specs/openapi.yaml](openapi.yaml).

```
POST /api/posts                         → 201 Post | 403 not_group_member | …
  {"media_ids": ["…"], "visibility": "me",
   "visibility_group_id": "…", "group_ids": []}

Post: + "visibility_group": {"id": "…", "name": "снт Ромашка"} | null
      "visibility": "friends"           (у поста с видимостью группы)

PUT /api/posts/{postId}/visibility      без изменений; снимает группу
```

Почему видимость группы — новым полем, а не новым значением
`visibility`: [ADR-0028](../docs/adr/0028-new-enum-value-in-new-field.md).

| Код | HTTP | Когда |
|---|---|---|
| `not_group_member` | 403 | видимость группы, где автор не участник, или группы, которой нет |

## Модель данных

```sql
ALTER TABLE posts
    ADD COLUMN visibility_group_id uuid REFERENCES groups (id) ON DELETE SET NULL;
-- visibility получает значение 'group'; удаление группы переводит её
-- посты в 'me' (требование 9)
```

Условие видимости (013) получает ветку:

```sql
OR (p.visibility = 'group' AND EXISTS (
      SELECT 1 FROM group_members m JOIN groups g ON g.id = m.group_id
      WHERE m.group_id = p.visibility_group_id AND m.user_id = $viewer
        AND m.state = 'member' AND <группа видна смотрящему>))
```

## Ограничения и edge cases

| ситуация | поведение |
|---|---|
| `visibility_group_id` — группа, где автор приглашён | `403 not_group_member` |
| `visibility_group_id` не UUID | `403 not_group_member` |
| `visibility_group_id` + `visibility: "public"` | `400 invalid_request` |
| `visibility_group_id` + `visibility: "all"` | видимость группы; `all` не учитывается |
| `visibility_group_id: ""` | видимость по `visibility` |
| Взаимный подписчик, не участник X | поста нет нигде, `404` |
| Участник X, автор закрыл профиль | пост виден: закрытость касается `all` |
| Участник X заблокировал автора или наоборот | поста нет (022) |
| Хозяин группы по интересам X заблокировал участника | X тому не видна — пост не виден |
| Автор вышел из X | участники видят, автор видит как свой |
| Удалили группу X | пост «только мне», в `groups` X нет |
| Автор сменил видимость на `all` | пост виден всем, X в `groups` остаётся |
| Старая сборка смотрит пост группы | `visibility: friends`, отметка «друзьям» |
