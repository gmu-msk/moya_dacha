# moya_dacha_api

Клиент API МояДачи, **сгенерированный** из `specs/openapi.yaml`.

Руками здесь не правится ничего: любое изменение начинается с контракта,
дальше `make generate` из корня репозитория. CI проверяет, что содержимое
папки совпадает с тем, что получается из контракта — см.
[ADR-0001](../../../docs/adr/0001-spec-first-openapi.md) и
[ADR-0008](../../../docs/adr/0008-dart-client-generation.md).
