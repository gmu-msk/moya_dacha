# Демо-данные

SQL-файлы из этой папки применяются к базе демо-стенда после миграций,
по порядку имён: `001-...sql`, `002-...sql` и так далее. Здесь лежит
постоянный состав стенда — то, что нужно всем сценариям сразу
(сейчас это `001-users.sql`: три зарегистрированных номера). Данные
конкретного сценария живут в его папке, `demo/stories/<сценарий>/seed.sql`.

Данные здесь — выдуманные: стенд поднимается на машине разработчика и
показывается людям, поэтому настоящим номерам телефонов и чужим фотографиям
тут не место.

Наливаются они одним и тем же набором каждый раз, так что стенд
воспроизводим: `make demo-reset && make demo` возвращает его в исходное
состояние. Стенд без сценария поднимается с «Живой дачей»
(`demo/stories/000-dacha`): пятнадцать дачников, шестьдесят постов,
лайки и разговоры.

Рядом лежит `media/` — фотографии постов и аватары. Они нарисованы кодом
из `draw/` (`cd demo/seed/draw && go run .` перерисует их заново, те же
самые): настоящих снимков тут быть не должно, а одинаковые заглушки
не показывают, как выглядит лента. Строки в базе ссылаются на файлы
в хранилище, а файл в базу не положишь, поэтому `demo/seed.sh`
раскладывает их в хранилище стенда под ключами `demo/…`. Весят они
около 9 МБ: фотографии в том же размере, что и настоящие, — 1600 по
большей стороне, аватары 512×512 (ADR-0011).
