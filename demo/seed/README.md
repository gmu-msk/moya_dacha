# Демо-данные

SQL-файлы из этой папки применяются к базе демо-стенда после миграций,
по порядку имён: `001-...sql`, `002-...sql` и так далее. Здесь лежит
постоянный состав стенда — то, что нужно всем сценариям сразу
(сейчас это `001-users.sql`: три зарегистрированных номера). Данные
конкретного сценария живут в его папке, `demo/stories/<сценарий>/seed.sql`.

Данные здесь — выдуманные: стенд поднимается на машине разработчика и
показывается людям, поэтому настоящим номерам телефонов и чужим фотографиям
тут не место.

Наливаются они одним и тем же набором каждый раз, так что стенд
воспроизводим: `make demo-reset && make demo` возвращает его в исходное
состояние.

Рядом лежит `media/` — фотографии-заглушки (цветные градиенты разных
пропорций). Строки в базе ссылаются на файлы в хранилище, а файл в базу
не положишь, поэтому `demo/seed.sh` раскладывает их в хранилище стенда
под ключами `demo/…`. На них ссылаются сценарии, которым нужны готовые
посты, — например лента (`demo/stories/004-feed/seed.sql`).
