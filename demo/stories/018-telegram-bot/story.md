# Telegram-бот

## Что показываем
Бота в эмуляторе не видно: он живёт в сервисе и говорит с Telegram.
Сценарий поднимает стенд с «Живой дачей» и обычное приложение, а бот
проверяется на проде, в настоящем Telegram, после мерджа.

Чтобы бот ожил, нужно один раз: создать бота у @BotFather, положить токен
в секрет репозитория `TELEGRAM_BOT_TOKEN`, свой ник Telegram без `@` —
в переменную репозитория `TELEGRAM_OWNER`, и дождаться деплоя из main
(или запустить «Деплой» вручную).

## Данные
«Живая дача» ([000-dacha](../000-dacha/story.md)): бот отвечает сводкой
по ней, если стенд запущен с токеном бота.



## Что проверить руками
- [ ] `/start` боту в личку — «Готово: сюда будут приходить тревоги и тестовые сборки.»
- [ ] Бот добавлен в группу, `/group` там — «Готово: сюда будут приходить сборки приложения.»
- [ ] `/status` в личке — «Всё в порядке», люди и посты, ошибки, машина
- [ ] В личке у бота есть кнопка «Меню» со списком команд (после
      деплоя или `/start`; Telegram иногда показывает меню только после
      перезахода в чат)
- [ ] Меню → `/invite` → бот просит номер → номер текстом или контакт из
      книги → в ответ номер и код; этим кодом входится в приложение
- [ ] `/invites` — только что выданное приглашение с 5 попытками,
      `/uninvite <номер>` — отзывает
- [ ] `/invite` в группе — «Приглашения — только в личке бота.»
- [ ] Кто-то другой пишет боту `/start` — подсказка, как написать отзыв (019)
- [ ] Кто-то не из группы тестировщиков пишет боту в личку — «Отзывы здесь
      принимаются только от тестировщиков МоейДачи.», задачи нет (019)
- [ ] Владелец сменил ник в Telegram — `/status` и `/invite` по-прежнему
      работают: после `/start` бот узнаёт владельца по id, а не по нику
- [ ] После мерджа следующего PR сборка сама приходит в группу со «Что нового» — файлом, а если APK больше 50 МБ, ссылкой «Скачать:»
- [ ] Пуш в PR — владельцу приходит ссылка на тестовую сборку
- [ ] Тревога приходит в личку за минуту, «всё в порядке» — когда прошла
