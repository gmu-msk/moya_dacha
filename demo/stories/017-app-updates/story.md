# О приложении и «Что нового»

## Что показываем
Экран «О приложении» с образцом сведений о сборке: версия, номер сборки,
дата, коммит и список «Что нового». В обычном приложении он открывается
кнопкой «О приложении» внизу «Изменить профиль».

Обновление поверх, окно «Что нового» после обновления и полоса «Вышла
новая версия» в эмуляторе не показываются: у сборки для эмулятора номер 0,
и она обновлений не ищет. Их проверяют на телефоне по APK из PR и из main.

## Данные
Не нужны: экран в сеть не ходит.

## Что проверить руками
- [ ] Видны версия 1.0.0, сборка 386520, дата 26.09.2026 и коммит aa652ef
- [ ] Ниже «Что нового» с двумя строками
- [ ] Тёмная тема и крупный шрифт: всё читается, ничего не обрезано
- [ ] На телефоне: APK из этого PR ставится поверх сборки из main только
      после одного удаления старой; следующий пуш в PR — уже поверх
- [ ] На телефоне после обновления один раз показывается «Что нового»
- [ ] На телефоне в «Изменить профиль» → «О приложении» — номер сборки
      из комментария с APK
