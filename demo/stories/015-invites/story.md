# Вход по коду приглашения

## Что показываем
Сервис в режиме приглашений: войти можно только по личному коду, который
владелец выдал на конкретный номер. Экран входа тот же, но после «Получить
код» приложение просит код из приглашения, ничего не отправляет и не
предлагает отправить ещё раз. Номера без приглашения сервис не пускает.

## Данные
Стенд поднимается с `AUTH_INVITES=1` (`story.env`), общий код `0000`
в этом режиме не действует. Приглашения из `seed.sql`:

- `+7 900 000-00-01` — Николай, уже зарегистрирован, код **4821**
- `+7 900 555-00-01` — новый человек, код **7306**
- `+7 900 000-00-02` — Валентина, приглашения нет

## Что проверить руками
- [ ] Номер `9000000001`, «Получить код» — заголовок «Введите код»,
      под ним «Введите код из приглашения для +7(900)000-00-01»; кнопки
      «Отправить код ещё раз» нет, «Другой номер» есть
- [ ] Код `0000` — «Неверный код»: общий код стенда здесь не работает
- [ ] Код `4821` — вход уходит сам, «С возвращением, Николай!»
- [ ] Выйти из профиля и снова ввести `9000000001` — под полем номера
      «Для входа нужен код приглашения…»: приглашение сгорело при входе
- [ ] Номер `9000000002` — тот же отказ под полем номера
- [ ] Номер `9005550001` и код `7306` — открывается «Знакомство»:
      новый пользователь завёлся по приглашению
- [ ] Выдать новое приглашение Николаю:
      `docker compose -f docker-compose.demo.yml exec api moya-dacha-server invite 89000000001`
      печатает номер и код; с этим кодом Николай снова входит
- [ ] `… exec api moya-dacha-server invites` — список действующих
      приглашений без кодов; `… uninvite 89000000001` — отзыв
