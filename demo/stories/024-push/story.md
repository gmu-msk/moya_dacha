# Пуши

## Что показываем
Пуш в шторку телефона о новом уведомлении: кто отметил пост, ответил на
него, подписался, принял заявку или хочет подписаться. Касание пуша
открывает пост или профиль (specs/024-push.md).

В эмуляторе пушей не видно: в нём нет Google Play, а эмуляторная сборка
идёт без настроек Firebase. Сценарий поднимает стенд с «Живой дачей»,
и видно главное для эмулятора: без Firebase приложение работает как
раньше и о разрешении не спрашивает. Сами пуши проверяются на телефоне,
после мерджа: отправляет их сервер прода, а он собран из main.

Чтобы пуши ожили, нужно один раз:
1. [Консоль Firebase](https://console.firebase.google.com) → создать
   проект (Google Analytics не нужна).
2. В проекте добавить Android-приложение с пакетом `ru.moyadacha.app`,
   скачать `google-services.json` и положить его содержимое целиком
   в секрет репозитория `GOOGLE_SERVICES_JSON`.
3. Настройки проекта → «Сервисные аккаунты» → «Создать закрытый ключ».
   Содержимое скачанного JSON целиком — в секрет
   `FIREBASE_SERVICE_ACCOUNT`.
4. Смёржить PR или запустить «Деплой» вручную. В итоге прогона строка
   «Пуши: Firebase принял ключ, проект …».

## Данные
«Живая дача» ([000-dacha](../000-dacha/story.md)), код на стенде `0000`,
как в [014-notifications](../014-notifications/story.md).

## Что проверить руками

В эмуляторе (`make story STORY=024-push`):
- [ ] Вход Николаем `+7 900 000-00-01` — лента, вопроса о разрешении
      уведомлений нет, колокольчик и раздел работают как раньше

На телефоне, после деплоя из main (свежий APK прода по ссылке из группы):
- [ ] Первый вход — Android спрашивает «Разрешить приложению МояДача
      отправлять уведомления?»; после перезапуска больше не спрашивает
- [ ] Со второго телефона (или попросить тестировщика) отметить свой пост,
      свернув приложение на первом, — через ~10 секунд в шторке «<ник> —
      отметил ваш пост», значок — штакетник с маком
- [ ] Ещё отметка того же поста — строка в шторке не вторая, а та же:
      «и ещё 1 отметили ваш пост»
- [ ] Касание пуша — открылся раздел «Уведомления» и в нём этот пост;
      «Назад» — к разделу
- [ ] Комментарий — «ответил на ваш пост: «…»», касание открывает пост
- [ ] Подписка — «подписался на вас», касание открывает профиль
- [ ] Закрыть профиль, заявка со второго телефона — «хочет подписаться на
      вас», касание открывает раздел с заявкой сверху
- [ ] Лайк и сразу снять — пуша нет
- [ ] Приложение открыто — пуш в шторку не падает, загорается точка на
      колокольчике
- [ ] Приложение смахнуто из недавних — пуш всё равно приходит, касание
      открывает приложение сразу на посте
- [ ] Выйти из аккаунта — пуши на этот телефон больше не приходят
- [ ] Тёмная тема и крупный шрифт — экраны те же, что в 014; пуш рисует
      сам Android
