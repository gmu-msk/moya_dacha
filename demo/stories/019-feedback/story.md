# Обратная связь

## Что показываем
Обычное приложение на «Живой даче». Войти Николаем (+7 900 000-00-01,
код из стенда), открыть «Изменить профиль» → «Написать разработчику».
Сверху форма отзыва, ниже «Мои отзывы» во всех статусах: вышло в сборке,
одобрено, не будем делать, задача заведена.

Задачи GitHub и ответы бота в эмуляторе не видны: стенд идёт без токена
GitHub, отзыв остаётся «Отправлено». Путь до задачи и ответы в Telegram
проверяются на проде после мерджа, когда в секрете репозитория
`FEEDBACK_GITHUB_TOKEN` лежит fine-grained токен на этот репозиторий
с правом Issues: read and write.

## Данные
«Живая дача» ([000-dacha](../000-dacha/story.md)) и пять отзывов: четыре
Николая в разных статусах и один из Telegram без задачи — его видно на
дашборде.

## Что проверить руками
- [ ] «Написать разработчику» есть над «О приложении»
- [ ] В «Моих отзывах» четыре отзыва, сверху новый, статусы «Задача #78»,
      «Не будем делать, #75», «Одобрено, #74», «Вышло в сборке 386950»
- [ ] Пустой текст не отправляется; скриншот прикладывается и убирается
- [ ] Отправленный отзыв появляется первым со статусом «Отправлено»,
      форма очищается, видно «Спасибо! Отзыв отправлен.»
- [ ] Дашборд (`/dashboard`): блок «Отзывы», за неделю — 6 после своей
      отправки, последние отзывы со ссылками на задачи
- [ ] На проде: отзыв из приложения — задача «входящее» + «из приложения»
      со скриншотом, версией и телефоном
- [ ] На проде: `/ideas` в теме «Идеи и баги»; сообщение там и в личке
      боту — задача и ответ «Спасибо! Записал как задачу #N…»
- [ ] На проде: `/входящие`, `/одобрить N` — автору «Задачу #N одобрили…»
- [ ] На проде: после сборки main в группе автору «Задача #N вышла в сборке…»
