# Вход по номеру телефона

## Что показываем
Человек открывает приложение, вводит номер телефона, получает код и
попадает внутрь. Регистрация и вход — одно действие: новый номер заводит
пользователя, известный — просто впускает.

Код на стенде фиксированный — **0000**: SMS-провайдер не выбран, и стенд
поднимается с `AUTH_FIXED_CODE=0000`, чтобы фичу можно было показать без
SMS (specs/001-auth.md). В проде код случайный и уходит в лог сервиса,
откуда его выдают вручную.

## Данные
Три номера на стенде уже зарегистрированы (общие данные стенда,
`demo/seed/001-users.sql`):

- `+7 900 000-00-01` — Николай
- `+7 900 000-00-02` — Валентина
- `+7 900 000-00-03` — Пётр

Своих данных сценарию не нужно: второй случай — вход с номера, которого
на стенде нет, — показывается любым другим номером, придуманным на месте.

## Что проверить руками
- [ ] На экране входа заголовок «Вход в аккаунт», в поле уже стоит
      `+7(000)000-00-00`: `+7` тёмное, остальное светлее, курсор мигает
      сразу за `+7`
- [ ] Набрать `9000000001` — цифры встают на места нулей, светлый хвост
      никуда не девается, а «Получить код» оживает только на последней
      цифре
- [ ] Попробовать ввести букву — в поле её нет, форма подсвечивается и
      качается
- [ ] «Получить код» — экран кода, в поле `____`, кнопка «Отправить код
      ещё раз через 60 сек» неактивна и отсчитывает вслух
- [ ] Набрать код `0000` — вход уходит сам после четвёртой цифры,
      приложение пишет «С возвращением, Николай!»
- [ ] Аватар в заголовке открывает профиль, «Выйти» внизу профиля
      возвращает на экран входа: профиль закрывается вместе с сессией
- [ ] Набрать `89000000001` подряд — лишняя восьмёрка отбрасывается сама,
      в поле `+7(900)000-00-01`, и код `0000` впускает того же человека
- [ ] Незнакомый номер, например `9005557788`, и код `0000` —
      открывается «Знакомство»: пользователь завёлся этим входом, но
      имени у него ещё нет (specs/002-profile.md)
- [ ] Неверный код `1111` — под полем слева «Неверный код», поле снова
      пустое, экран не меняется
- [ ] «Другой номер» — поле номера пустое, и «Получить код» на том же
      номере в первую же минуту даёт сообщение «На номер … код уже был
      отправлен… через N сек» с убывающим счётчиком; кнопка неактивна,
      а стоит поправить номер — снова активна
- [ ] Дождаться нуля на счётчике — сообщение исчезает само
- [ ] Номер `4951234567` (городской) — «Это не похоже на номер
      мобильного телефона» под полем
- [ ] Закрыть приложение и открыть заново — оно открывается сразу внутри,
      без входа
- [ ] В логах стенда виден выданный код: `make demo-logs`, строка
      «код подтверждения»
